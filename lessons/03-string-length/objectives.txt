LESSON 3: OBJECTIVES
===================

After the core exercises, you should be able to:

  [ ] Distinguish a buffer's stored size from a null-terminated string length.
  [ ] State the readable-memory precondition for an unbounded string scan.
  [ ] Trace CMP, JE, INC, and JMP using a loop invariant.
  [ ] Explain indexed byte addressing and the return value in RAX.
  [ ] Assign register-preservation responsibilities to caller and callee.
  [ ] Explain why this leaf procedure needs no stack allocation.

Completion: Tiers 1 and 2 in exercises.txt, including the empty-string and
embedded-zero cases. Byte-counting extensions are optional.
