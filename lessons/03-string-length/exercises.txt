LESSON 3: EXERCISES
===================

TIER 1: OBSERVE (CORE)
---------------------

1. Build and run the original program. Expected status: 26, including CRLF.

2. Replace the ENTIRE message declaration for each test, keeping the EQU
   expression and the procedure unchanged:

       Declaration                  Expected status
       message db 0                 0
       message db "Hi", 0           2
       message db "Hi", 13, 10, 0   4
       message db "ABC", 0          3

   The status tests string_length, not WriteFile success. A zero-length write
   has device-dependent behavior and is not an I/O test here.

TIER 2: EXPLAIN (CORE)
----------------------

3. Trace "ABC",13,10,0 by hand. Use the invariant in lesson.txt and show the
   final iteration. Explain why moving INC before the zero check would break the
   count for an empty string.

4. Use "message db 'AB',0,'CD',0". Predict both message_length and the return
   from string_length. Expect 5 and 2 respectively. The executable's status
   checks the runtime count; EQU can be checked directly in the source or an
   assembler listing.

5. Add "name_text db 'Alice',0". Have main call string_length on that string and
   exit with its result. Expected status: 5. The same procedure must work
   without referring to the name of either data label.

6. Explain why RAX need not be saved by string_length. What would change if its
   implementation used RBX as a scratch register? Do not implement that change
   until you have studied the prologue in Lesson 4.

TIER 3: APPLY (OPTIONAL)
-----------------------

7. Implement count_char:

       RCX = valid null-terminated byte string
       EDX = ASCII byte value to count (second argument; use DL to compare)
       RAX = number of matches BEFORE the terminator

   Use only volatile registers and no nested calls. Tests:
       "banana",0 with 'a' -> 3
       "banana",0 with 'x' -> 0
       0 with 'a'          -> 0

8. Implement bounded_length:

       RCX = buffer readable for RDX bytes
       RDX = maximum number of bytes to examine
       RAX = index of the first zero, or RDX if no zero occurs in that range

   Check the bound BEFORE reading a byte. RDX = 0 must make no memory access.
   CMP and JE suffice when your index starts at zero and advances by one.
   Tests: "ABC",0 with limits 0, 2, 4 -> results 0, 2, 3.
   Explain why a result equal to the limit does not prove termination.

Keep variants separate or restore the original message when finished.
